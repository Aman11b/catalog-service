# catalog-service

Legacy product catalog microservice built with **Node.js** and **Express**, originally using AWS services.

## Tech Stack

- **Backend:** Node.js, Express.js
- **Legacy Infrastructure:** AWS DynamoDB, Amazon S3
- **Target Infrastructure:** Google Cloud Platform (GCP)
  - Firestore
  - Google Cloud Storage (GCS)
  - Cloud Spanner
  - Cloud Run

## Migration

The service is being migrated from AWS to GCP, with the goal of modernizing the infrastructure while maintaining the existing product catalog functionality.

## Status

🚧 Work in progress — migrating from AWS to GCP.
